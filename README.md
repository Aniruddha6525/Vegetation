# Vegetation

A Unity project for realistic vegetation, terrain environments, and nature assets.

## Project Details
- **Unity Version:** 2022.3.48f1 (LTS)
- **Render Pipeline:** Universal Render Pipeline (URP)
- **Large File Storage:** Git LFS is configured for binary assets (`.fbx`, `.psd`, `.tif`, textures, and 3D models).

## Getting Started
1. Ensure [Git LFS](https://git-lfs.com/) is installed:
   ```bash
   git lfs install
   ```
2. Clone the repository:
   ```bash
   git clone https://github.com/Aniruddha6525/Vegetation.git
   ```
3. Open the project using **Unity 2022.3.48f1**.
